# 少儿编程用户画像展示设计

## 1. 核心数据展示

### 用户基本信息
- 昵称
- 年龄
- 学习时长

### 课程完成进度
- 已完成/总课程数

### 编程能力雷达图（AI评估）
```javascript
const radarOption = {
  tooltip: { trigger: 'item' },
  radar: {
    indicator: [
      { name: '逻辑思维', max: 100 },
      { name: '创造力', max: 100 },
      { name: '问题解决', max: 100 },
      { name: '代码规范', max: 100 },
      { name: '空间想象', max: 100 }
    ]
  },
  series: [{
    type: 'radar',
    data: [{ value: [85, 72, 68, 90, 76], name: '能力评估' }]
  }]
};
```

### 热力图

   用户打卡热力图
   展示用户在一段时间内的学习打卡情况，通过颜色深浅表示打卡次数。

### 学习建议与资源推荐
